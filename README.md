# Customer Churn Prediction & Lifetime Value (LTV) Engine

## Project Overview

The **Customer Churn Prediction & Lifetime Value (LTV) Engine** is a data analytics and machine learning project designed to identify customers who are at risk of leaving a business and estimate their potential customer lifetime value.

The project combines:

- Exploratory Data Analysis (EDA)
- Data cleaning and preprocessing
- Customer churn prediction
- Customer Lifetime Value (LTV) analysis
- Machine learning model development
- Model evaluation
- Churn probability and risk classification
- Retention prioritization
- FastAPI-based prediction service
- Power BI dashboard and business reporting
- Model and project documentation

The project uses the **IBM Telco Customer Churn dataset**, containing approximately 7,043 customer records.
