The dataset was cleaned and validated by checking for duplicates, missing values, and appropriate data types. Categorical variables were encoded for analysis and modelling, and unnecessary columns were removed. Feature engineering was performed by creating Tenure Group, Total Services, and Support Services to capture useful customer behaviour patterns. Potential target leakage was also addressed by excluding Churn Value, Churn Score, and Churn Reason from the modelling features, while retaining Churn Label as the target variable.
